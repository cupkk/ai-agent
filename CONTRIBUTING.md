# Contributing

Thanks for helping improve this project.

## How to contribute

1. Open an issue before starting a large change to the assistant workflow, API, integrations, or data model.
2. Keep changes focused and document whether they affect the backend, frontend, WeChat integration, calendar sync, document analysis, or meeting-audio workflow.
3. Do not commit API keys, OAuth secrets, user files, meeting recordings, calendar data, local databases, or cloud credentials.
4. Add or update tests or validation notes when changing authentication, file upload, AI prompts, scheduling, or integration behavior.
5. Run the relevant local checks before opening a pull request.

## Pull request expectations

Pull requests should include:

- What changed and why
- Which user workflow or integration is affected
- How the change was validated
- Any privacy, security, quota, or API-key considerations

Maintainers may ask for smaller patches, additional validation, or clearer separation between implemented and planned features.
